# Quick Button Box（快捷按钮盒）

把各插件的「快捷按钮」（Quick Action，与快速区同一套按钮）收纳进一个抽屉网格块，做成自己的按钮集合。同一按钮放快速区还是放盒里由你决定，状态共享、显示样式一致。

- **抽屉块 `quickbuttonbox.grid`**：网格内是纯图标按钮宫格，悬停显示动作名；开关类动作带点亮态（如防休眠开启时高亮）；`requiresConfirmation` 的重动作点击先弹确认。
- **装填**（编辑模式）：打开 设置 → 组件 页，把插件分区里的「快捷按钮」拖到抽屉中的按钮盒上即加入；同一张卡也可拖到快速区（单击则加入快速区末尾）。原件保留在快速区时双入口共享同一状态。盒块齿轮面板可移除 / 排序。
- **容量**：按块尺寸自适应宫格，装填放不下会拒绝（换更大尺寸：大 2×2 / 特大 4×2）。
- **数据**：每个盒放置实例的动作顺序存于该实例的 placement 存储，多实例互不干扰；动作来源插件被禁用后对应按钮置灰保留。
