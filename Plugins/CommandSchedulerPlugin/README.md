# Command Scheduler（定时命令）

按计划自动执行本机 shell 命令，并保留每次执行的输出历史。

## 提供的块

- **抽屉块 `command.scheduler`**：任务列表为主视图，块内无标题行、无工具行。每行 = 状态点 / 任务名 / 调度摘要 / 下次触发 / 上次结果 / 「立即运行」/ 启停开关。
  - 点行 → **历史浮窗**：宽卡左列该任务的执行记录、右列选中记录的输出（含当时的命令快照）；卡片窄于 420pt 时改单栏（记录在上、输出在下）。
  - 长按行 → **编辑表单**。
  - 块内唯一控件：鼠标悬浮时**右上角浮出**的 `+`（新建任务），与宿主编辑角标同一环。插件设置（默认守卫超时 / 输出目录维护）走宿主块左上角的齿轮，块内不再有第二个齿轮入口。
  - 尺寸三档 `300×300` / `660×460` / `960×760`：最小块只给浮窗卡片 252×252，历史卡因此切单栏、表单卡靠卡片内滚动，功能不残但日志看不了几行。
- **活动摘要 `command.scheduler.summary`**：有任务在执行时在刘海紧凑带显示「N 条命令运行中」；无执行但有失败任务时改显示警示。

## 行为约定

- **只在宿主运行时执行。** 调度活在 NotchCenter 进程内，宿主没运行就没有任何任务执行；宿主退出、崩溃或被禁用时正在跑的进程组会被杀掉，该次记为「已中止」（不是失败）。机器睡眠期间错过的时刻**不补跑**，只在任务卡上聚合成「错过 N 次」。
- **shell 是非登录的 `/bin/zsh -c`**，PATH 由插件显式注入（继承宿主 PATH 再补 `/opt/homebrew/bin`、`/usr/local/bin`、`~/.local/bin`、`~/.bun/bin`、`~/.cargo/bin`、`~/Library/pnpm` 等）。不读 `.zprofile` / `.zshrc`——那里的 `echo` 会污染任务日志且让结果不可复现。需要 nvm 之类的初始化时，在命令里显式写 `source ~/.nvm/nvm.sh && nvm use 18 && …`。
- **工作目录** 默认 `$HOME`，任务级可覆盖；保存时**不校验目录是否存在**（定时任务跑在未来，外挂卷可能那时才挂载好），运行时失败并如实记录。
- **同一任务不重叠**：上一次还在跑时，本次到点直接跳过并记入「跳过」。不同任务各自独立并发，不做全局队列。
- **守卫超时**默认 30 分钟（插件设置里可改），任务级可单独设置或关闭。超时先 `SIGTERM` 整个进程组、5 秒后 `SIGKILL`——杀的是进程组而不是直接子进程，否则 `zsh -c "a | b"` 里的 `b` 会变成孤儿继续写日志。
- **输出**边跑边落盘（长任务能看进度，进程被杀也留下已产生的部分）。单次输出文件上限 1MB；查看时按「头部 64KB + 尾部 64KB」投影，中间标注省略字节数。ANSI 转义码保留在文件里，显示时剥离。
- **保留策略**：每任务最近 50 次 + 输出目录总量 200MB，超出按最旧删。设置浮窗里可查看输出目录位置、一键清空。
