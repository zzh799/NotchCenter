# Media Controls（媒体控制）

控制系统当前正在播放的媒体（播放 / 暂停 / 上一首 / 下一首），并显示曲目信息与播放进度。控制系统任意 App 的全局「正在播放」会话——Spotify、Apple Music、播客与浏览器标签页都适用。

## 提供的块

- **抽屉块 `media.controls`**（大 / 超大）：当前曲目的封面、标题与艺术家、播放进度条与时间，以及播放 / 暂停、上一首、下一首控制。

## 正在播放摘要

有媒体正在播放时，插件经活动摘要通道（宿主 `HostController.showActivitySummary`）在刘海紧凑带内显示一颗迷你芯片：

- 曲名 + 艺术家与底部迷你进度条实时跟随播放进度；暂停时图标切换为暂停并停在当前位置。
- 停止播放 / 没有可播内容时芯片自动收回。

## 实现说明

- 播放状态是系统级瞬态：以插件级共享单例（`MediaPlayerController`）持有，每秒轮询系统 Now Playing 会话 + 变更通知即时补拉，不写本地存储。
- 控制能力来自 macOS **私有框架 MediaRemote**（仅 `dlopen`/`dlsym` 运行时访问，封装在 `MediaRemoteSession`，是插件内唯一的私有 API 接触面）。系统不提供此会话时，控制卡显示「媒体控制不可用」降级提示，不影响宿主与其他插件。
- 控制命令（播放 / 暂停 / 切曲）投递到系统当前 Now Playing 会话，由系统转发给正在播放的 App；个别播放器不支持某些命令时无副作用。

## 注意

- 封面图按曲目缓存（NSCache），仅在换曲 / 封面变化时解码，避免每秒重复解码。
- 滑块暂不提供拖动定位（seek）：控制范围限定为播放 / 暂停与上下曲。
- 禁用插件或退出 NotchCenter 会停止轮询并收回摘要。
