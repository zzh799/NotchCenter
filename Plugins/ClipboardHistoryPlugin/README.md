# Clipboard History（剪贴板历史）

记住最近复制的**文本、图片与文件**：在抽屉列表里回查、搜索、置顶，点击条目即可写回剪贴板，再去目标处粘贴。

## 提供的块

- **抽屉块 `clipboard.history`**（大 / 超大，默认大）：顶部「搜索 / 清空」两颗组件默认圆形按钮默认隐藏、鼠标悬浮组件时才在左右上角显示（与编辑模式角标同一交互与样式），点搜索按钮展开搜索框，不占整行输入框、纵向空间全让给条目；置顶区 + 最近列表；条目单行显示，点击条目即写回剪贴板，长按条目浮窗预览内容，行尾「置顶 / 删除」按钮；写回后抽屉保持展开，方便连续复制多条。图片条目行比文本行高一档，行内直接给缩略图。
- **紧凑块 `clipboard.tray`**：刘海区图标，点击展开抽屉；暂停记录时图标变灰。

## 悬浮预览

鼠标在条目上**停稳约 0.4 秒**后，光标下方会浮出一张内容卡：图片给放大的预览，文本给前 8 行，文件给路径列表（多文件只列前几条 + 剩余数量）。移开鼠标即消失。

- 卡片**不吃点击**——它盖住下面的行时，点击照常落在那一行上。
- 卡片在块内浮动，不会超出组件范围，因此不会把抽屉顶掉。
- 要看全并可选中复制，仍然走长按：悬浮是"快速一瞥"，长按是"看全并取用"。

## 记录规则

### 文本

- 只记纯文本（首尾空白已清理），空串不记，单条超过 100KB 不记。
- 除正文外还会区分**链接**与**颜色**两种类型（由正文推断，供库页筛选）。

### 图片

- 记录复制时的**原始字节**，不做格式转换（PNG 还是 PNG、TIFF 还是 TIFF），写回时原样放回。
- 单张超过 **16MB** 不记；去重按内容哈希，同一张图重复复制只保留一条并顶到最前。
- **复制单个图片文件（png / jpg / heic / tiff 等）也按图片记录**：读的是文件内容，所以同样有预览、同样按图像写回。超过 16MB 的图片文件退回按文件引用记录（否则你连"复制过这个文件"都看不到）。
- 图片正文为空——**搜索不覆盖图片条目**，这是刻意的：没有可搜的文本就是没有。
- 路径落在 `~/Library/Caches/` 下的文件引用**不收**：那是程序自建的可丢弃缓存区，出现在剪贴板上的缓存路径是别的进程（输入法、剪贴板同步工具）回写的中间产物，不是你要复制的东西。

### 文件

- 只记**路径引用**，不复制、不移动、不删除你的原文件。
- **单个图片文件不走这里**（见上节）；一次选中多个文件时，即使全是图片也仍按文件引用收，聚合为**一条**条目——一次复制的原子单位是那一组，不拆。
- 原文件被移动或删除后，该条目写回会失败并在行内提示「文件已移动或删除」。粘贴前请确认文件还在原处。

### 通用

- 连续重复不新增；命中旧条（含置顶）会把它顶到最前面并保持置顶。
- 最多保留 50 条（含置顶），置顶最多 5 条；只按条数与媒体字节预算淘汰，本身不按时间过期——时间维度的清理交给「自动清理」（见设置，默认每周）。
- 图片另有 **200MB** 总字节预算：超预算时从最老的未置顶图片开始淘汰，**置顶条目永不因预算被淘汰**。
- 标记为 transient / concealed 的内容（如密码管理器的自动清除型复制）会被跳过；暂停期间复制的内容不补记。

## 设置

- 状态栏菜单：暂停 / 恢复记录、清空未置顶条目。
- 每放置实例可单独设置：显示条数（20 / 50）。
- **自动清理（全局设置）**：`关闭 / 每天 / 每周（默认）/ 每月`。到点自动执行一次与「清空未置顶」完全相同的清理——删掉当时**全部未置顶**条目，置顶条目始终保留（图片文件连带回收）。周期是**清理频率**不是保留时长：选每周就是每周清一次。首次启用（新装 / 升级）只起算、不立刻清；**改档也从此刻重新起算**，不会因为顺手试一下档位就把历史清掉。两个入口都能改：抽屉块齿轮（实例设置浮窗的「全局」一节）、库页块齿轮（插件级设置）。
- 一键清空只删未置顶条目（浮层二次确认，不弹模态窗口），置顶条目必须手动取消置顶后才会消失。
- 库页（`clipboard.library`）另有类型筛选：文本 / 链接 / 颜色 / 图片 / 文件，可与搜索叠加。

## 隐私说明

- 历史以**明文**保存在本机插件数据目录（`PluginData/com.notchcenter.clipboard/`），不加密、不上传、不离开本机。文本与文件路径存在键值文件里，**图片原图与缩略图以文件形式存在同目录的 `Media/` 子目录**。
- 截图可能包含密码、聊天记录、客户资料等敏感内容，且同样以明文落盘。介意的话请在复制敏感内容前先暂停记录，或事后一键清空；删除单条条目会连带删掉它的图片文件。
- 不想手动清空的话，把「自动清理」设成每天 / 每周 / 每月，让它定期把未置顶历史（含图片文件）清掉；只留置顶条目。
- 不需要任何系统权限；不监听键盘，只轮询剪贴板变化（常驻每 0.5 秒一次，随插件启用 / 禁用起停，与抽屉是否打开无关）。

## 注意

- 不记富文本：复制带格式的网页段落只保留纯文本。
- 图片条目（**含由图片文件生成的条目**）写回的是**图像数据本身**。往 Finder 里 `Cmd+V` 贴它不会有反应（Finder 只接受文件引用），这是既定行为，不是 bug——想要文件请直接拖原文件。
- 复制图片文件时会把它的字节**快照**进插件数据目录：快照不跟随原文件的后续修改，删掉原文件也不会释放这份快照（要清就在列表里删条目或清空）。
- 不提供「复制为文件」动作，也不做「直接粘贴到前台 App」：写回剪贴板后请自己按 `Cmd+V`。
- 文件条目是路径引用而非副本，原文件失效后无法补救（不会替你拷贝一份）。
- 常驻每 0.5 秒轮询一次剪贴板（与抽屉是否打开无关）；纵向列表不消费横向滑动，其上滑动照常切换抽屉页面。
- 两次复制间隔小于 0.5 秒时只会留下后一条：前一条已被系统覆盖，任何轮询方案都无法恢复（macOS 不提供剪贴板变更通知）。
