# Clipboard History（剪贴板历史）

记住最近复制的纯文本：在抽屉列表里回查、搜索、置顶，点击条目即可写回剪贴板，再去目标处粘贴。

## 提供的块

- **抽屉块 `clipboard.history`**（大 / 超大，默认大）：顶部工具行默认只露「搜索 / 清空」两颗组件默认圆形按钮（不占整行输入框，纵向空间让给条目），点搜索按钮展开搜索框；置顶区 + 最近列表；条目单行显示，点击条目即写回剪贴板，长按条目浮窗预览全文，行尾「置顶 / 删除」按钮；写回后抽屉保持展开，方便连续复制多条。
- **紧凑块 `clipboard.tray`**：刘海区图标，点击展开抽屉；暂停记录时图标变灰。

## 记录规则

- 只记纯文本（首尾空白已清理），空串不记，单条超过 100KB 不记。
- 连续重复不新增；命中旧条（含置顶）会把它顶到最前面并保持置顶。
- 最多保留 50 条（含置顶），置顶最多 5 条；默认只按条数淘汰，永不过期。
- 标记为 transient / concealed 的内容（如密码管理器的自动清除型复制）会被跳过；暂停期间复制的内容不补记。

## 设置

- 状态栏菜单：暂停 / 恢复记录、清空未置顶条目。
- 每放置实例可单独设置：显示条数（20 / 50）。
- 一键清空只删未置顶条目（浮层二次确认，不弹模态窗口），置顶条目必须手动取消置顶后才会消失。

## 隐私说明

- 历史以明文保存在本机插件数据目录（`PluginData/com.notchcenter.clipboard/`），不加密、不上传、不离开本机。
- 不需要任何系统权限；不监听键盘，只轮询剪贴板变化。
- 敏感复制请先暂停记录，或使用后一键清空。

## 注意

- v1 不记图片与文件、不做「直接粘贴到前台 App」（写回后请自己按 Cmd+V）。
- 抽屉打开时每秒轮询，收起时降频；纵向列表不消费横向滑动，其上滑动照常切换抽屉页面。
