# Pomodoro（番茄钟）

专注 / 休息循环计时器，参考 [JokerQianwei/Focus](https://github.com/JokerQianwei/Focus) 的设计：基于间隔效应，在专注期间按**随机间隔**响起提示音，提醒你进行一次短暂的微休息。

## 提供的块与快捷按钮

- **抽屉块 `pomodoro.timer`**：开始专注、暂停 / 继续、跳过与停止，显示当前阶段、倒计时、进度条与今日完成数。
- **大组件块 `pomodoro.page`**：大计时器 + 今日节奏 + 历史回顾三区，适合把番茄钟当成一面专注看板。它与其它抽屉块同权（可拖动 / 缩放 / 重排 / 与别的块同页共存），只是声明了"当前页被占用时另开一页"的添加落点偏好。见下方「大组件形态」。
- **快捷按钮**（可放入快速区或快捷按钮盒）：`pomodoro.toggle` 开始 / 停止、`pomodoro.start` 开始专注、`pomodoro.pause` 暂停 / 继续、`pomodoro.reset` 停止计时。

## 大组件形态（`pomodoro.page`）

- 尺寸三档 300×240 / 600×360 / 900×600，走与所有抽屉块一致的渲染路径（宿主卡片 + 宿主滚动），可拖动、可缩放、可跨页搬移、可参与一键重排。
- **添加落点**：声明 `placement: .newPageWhenOccupied`——从目录添加时若当前页已被占用就另开一页；落位之后与任何块完全同权，你随时可以把它拖去与别的块同页共存。
- 三大区：**大计时器**（倒计时 + 进度 + 控制，空闲态显示本次专注时长预告）、**今日节奏**（按 3 小时分段的柱状条 + 近 7 天完成数）、**历史回顾**（总览 + 微休息效果对照 + 结束方式分布）。
- 数据不足或已迁移旧版记录时，页面底部会标注来源与上限。

## 评分与数据记录

- **评分条**：每次专注自然完成后（不是手动跳过），抽屉块会整块变成评分版式、大组件顶部也会出现评分条——对本次专注打 1–5 分情绪分，或删除这条记录。
- **不可跳过、不可补评**：评分条只有「打分」与「删除」两个出口；有待评分时**不能开始下一个专注**（评分闸门，不弹窗，只把注意力引到评分条）。
- **60 分钟自愈**：若评分长时间无人处理（最坏情况：没放任何 `pomodoro.timer` / `pomodoro.page` 导致评分条无处可达），超过 60 分钟自动作废该记录并恢复计时。
- **明细记录**：每次专注落一条明细（起止 / 计划时长 / 结果 / 评分 / 关联微休息），每条微休息落一条明细（起止 / 时长 / 结束方式）。**全量保留**，硬上限 20000 条（超出丢最旧，页面会标注）。
- **旧数据迁移**：旧版按天汇总的 `stats` 只读迁移一次，落成对应日期的「日汇总兜底」，不伪造无评分明细、不丢数据。

## 活动摘要（紧凑带迷你进度）

会话进行中，NotchCenter 在刘海紧凑带内（贴刘海一侧）渲染一行**活动摘要芯片**——阶段图标 + 阶段名 + 剩余时间 + 迷你进度（宿主 `HostController.showActivitySummary`；**不新建窗口、不遮挡屏幕内容区**，替代旧活动岛机制）：

- 常驻显示当前阶段与剩余时间，按整秒刷新；暂停时图标与文案置暂停态。
- **微休息**期间同样经摘要提示；结束后回到专注并续记剩余时间。
- 抽屉展开期间摘要整体让位，收起后原位恢复。

## 设置

- **计时设置**：专注时间（5–90 分钟）、休息时间（1–30 分钟）。
- **随机提示音**：最小 / 最大间隔（提示音在两者之间随机调度）、微休息时长（5–60 秒）。
- **声音效果**：微休息中、开始音效、结束音效（系统内置音效可选，支持试听，可选静音）。

## 注意

- 番茄钟状态为插件级单例：多个放置实例与活动摘要共享同一次会话。
- 微休息期间专注剩余时间被冻结，回归后继续计算；随机提示音仅在专注阶段调度。
- 休息结束后若仍有一条待评分记录，计时会**冻结在「等待评价」阶段**（暂停 / 跳过均无效），直到打分、删除或超时自愈。
- 禁用插件或退出 NotchCenter 会自动停止会话并收回活动摘要。
