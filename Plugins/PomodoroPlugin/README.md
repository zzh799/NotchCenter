# Pomodoro（番茄钟）

专注 / 休息循环计时器，参考 [JokerQianwei/Focus](https://github.com/JokerQianwei/Focus) 的设计：基于间隔效应，在专注期间按**随机间隔**响起提示音，提醒你进行一次短暂的微休息。

## 提供的块

- **紧凑块 `pomodoro.toggle`**：点击开始 / 停止番茄钟，运行时图标点亮阶段色。
- **抽屉块 `pomodoro.timer`**（中等 / 大）：开始专注、暂停 / 继续、跳过与停止，显示当前阶段、倒计时、进度条与今日完成数。

## 活动摘要（紧凑带迷你进度）

会话进行中，NotchCenter 在刘海紧凑带内（贴刘海一侧）渲染一行**活动摘要芯片**——阶段图标 + 阶段名 + 剩余时间 + 迷你进度（宿主 `HostController.showActivitySummary`；**不新建窗口、不遮挡屏幕内容区**，替代旧活动岛机制）：

- 常驻显示当前阶段与剩余时间，按整秒刷新；暂停时图标与文案置暂停态。
- **微休息**期间同样经摘要提示；结束后回到专注并续记剩余时间。
- 抽屉展开期间摘要整体让位，收起后原位恢复。

## 设置

- **计时设置**：专注时间（5–90 分钟）、休息时间（1–30 分钟）。
- **随机提示音**：最小 / 最大间隔（提示音在两者之间随机调度）、微休息时长（5–60 秒）。
- **声音效果**：微休息中、开始音效、结束音效（系统内置音效可选，支持试听，可选静音）。

## 注意

- 番茄钟状态为插件级单例：多个放置实例与活动摘要共享同一次会话。
- 微休息期间专注剩余时间被冻结，回归后继续计算；随机提示音仅在专注阶段调度。
- 禁用插件或退出 NotchCenter 会自动停止会话并收回活动摘要。
