# Reminders（提醒事项）

抽屉里的提醒事项清单，读 macOS 真实数据（EventKit），可就地勾选完成。

- **抽屉块 `reminders.list`**：一块绑定一个数据源——某个具体清单，或一个跨清单的智能视图（今天 / 计划 / 优先级 / 全部）。智能视图的「今天」含**逾期**项，与 Reminders.app 同义。
- **三种尺寸形态**（宽 × 高双轴断点，阈值宽 300 / 高 300）：窄态是「清单名 + 计数 + 纯行列表」；宽态是「徽章 + 计数 + 名称同行头部 + 行列表」；大态是「头部两行大计数 + 名称 + 带分隔线的行列表」。版式骨架源自设计稿的三张参考卡；宽态头部自 2026-09-20 起 footer 上移，不复刻中卡的「计数沉底」（决策 `2026-09-20-reminders-wide-footer-to-top`）。
- **徽章用清单真实颜色**：`EKCalendar.cgColor` 取到的清单色作低 alpha 圆底、原色作符号（不用「实色底 + 白符号」——Reminders 调色板含黄色，白符号在黄底上不可读）。智能视图没有颜色可用，走中性圆底 + 语义符号。
- **勾选**：点击行即写 EventKit（不延迟落盘），条目从列表消失后底部出现 2.5 秒的撤销条，点「撤销」改回未完成。
- **切换清单**：鼠标悬浮块，点左上角齿轮，在设置浮窗里选（智能视图 / 具体清单）——这是唯一入口。选择按块实例持久化，多实例互不干扰。
- **顺序**：直接用 EventKit 的返回顺序，不自推排序键。注意该顺序**无文档承诺**——若实测发现它与 Reminders.app 显示的顺序不一致，会改为「到期日升序 → 优先级降序 → 创建时间升序」。
- **权限**：需要「提醒事项」访问权限。装载插件时**不会**弹任何系统窗；块内先显示引导态，点「权限设置」走宿主的权限管理面板，授权后切回 App 自动加载。
- **不做**：新建 / 编辑 / 删除提醒、本地通知、紧凑块、快捷按钮、活动摘要。行内只显示「勾选圈 + 标题 + 重复图标」，不显示到期日、优先级、备注与来源清单——严格对齐设计稿。
- **已知数据面边界**：EventKit **不暴露** Reminders.app 的清单自定义图标（只有私有 ReminderKit 能读），所以圆徽章用的是清单颜色 + 通用符号；同样原因，智能视图提供的是「优先级」而不是「旗标」。

尺寸三档：最小 150×150（窄态下限）、推荐 300×360、最大 900×600。低到 150×150 时行列表在块内滚动，不撑破块、不溢出到邻居。
