# Clock（时钟）

抽屉里的一块指针表盘：60 刻度 + 1–12 数字 + 时/分针，一瞥即知几点几分。

- **抽屉块 `clock.analog`**：固定 150×120（默认格下的 1×1）。表盘内切于短边、居中，全部尺寸按表盘直径等比换算——所以把格子调大调小，表盘都还是同一张脸。整点位刻度与数字、指针同为一种白，分位刻度明显暗一档（对齐参考小部件的明暗层次）。
- **点击**：打开时钟.app。长按与点击同义（不做次级面板）。
- **刷新**：只有时/分针，没有秒针，因此分针**每分钟跳一格**，不做秒级重绘；Mac 睡眠唤醒或抽屉重新展开时会重新校准。
- **不做**：秒针、数字钟形态、12/24 小时切换、世界时钟/时区换算、实例设置。想用秒表、闹钟或看别的时区，点开时钟.app 即可。
- **尺寸**：三档固定 150×120，可在网格里拖动，但不支持缩放——放大的表盘只需等比，本插件不做这件事是刻意的取舍（一个纯装饰块不该按需吃掉 2×2）。
