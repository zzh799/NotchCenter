# Album（相册）

抽屉里的一组照片块：一个会自己轮播，一个只展示你指定的那一张。来源可以是本地文件夹/图片文件，也可以是照片图库里的相册或某一张。

## 提供的块

### `album.carousel`（轮播，最小 150×150）

- **自动轮播**：默认每 8 秒换一张，档位 3 / 5 / 8 / 15 / 30 / 60 秒；顺序播放或随机播放。随机是"整轮洗牌"，两轮交界处不会连播同一张。
- **手动干预**：点击块 = 下一张（并重新开始计时）；悬停浮出上一张 / 暂停继续 / 下一张三个圆钮。
- **说明带**：块够大（≥ 180×150）时在底部压一条黑色渐变带，显示来源名与"第 N / M 张"。
- **计时只在你看得见的时候走**：抽屉收起即停表，展开才重新枚举来源（期间新增或删除的照片会立刻反映出来）。

### `album.photo`（单张，最小 75×60）

- 显示你选定的**一张**：本地图片文件，或图库里的某一张照片。
- 点击用默认应用打开原图（图库资产则打开照片.app）；悬停浮出刷新钮。
- 来源文件被移走或删除时显示"来源已不在原位"，不会静默变成空块。

## 来源与权限

| 来源 | 权限 | 说明 |
|---|---|---|
| 本地文件夹 / 图片文件 | 无 | 只记路径。macOS 拒绝访问 Desktop / Documents / Downloads 时块会提示改用别的目录，不会误报成图库问题 |
| 照片图库相册 / 某一张 | 照片（读取） | 首次使用需在「权限管理」里授权；未授权时块显示引导态，其余功能不受影响 |

设置入口是块左上角的齿轮（悬停浮出），每个块单独设置。

## 隐私

- **只读**：不复制、不移动、不删除、不改写你的原图，也不写入照片图库。
- **不联网**：不上传任何图片或元数据。（图库资产可能存放在 iCloud，此时由系统 Photos 框架自行下载，与本插件无关。）
- **本地处理**：所有解码、缩放、缓存都在本机内存里完成；缓存只保留按显示尺寸降采样后的位图，且按字节上限回收，原图从不驻留内存。
- **不落盘副本**：插件数据目录里只有你的选择（文件夹路径 / 相册与照片的标识符）与几个显示开关，没有图片副本。

## 不做

视频与 Live Photo 播放、图库写入（新建相册 / 导入）、图片编辑与滤镜、按人脸或地点筛选、幻灯片伴音。整页化的相册浏览也不在本插件范围内——抽屉块的定位是"瞥一眼"，需要翻阅时点开照片.app 即可。
