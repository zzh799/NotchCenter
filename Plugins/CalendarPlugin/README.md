# Calendar（日历）

抽屉里的当月速览：公历月网格 + 今日农历，一瞥即知今天几号、星期几落在哪一列。

- **抽屉块 `calendar.month`**：固定 150×150。头部是「公历月｜今日农历」（如「9月｜八月初十」），下面 7 列星期行与当月网格，今日为白色实心圆高亮。周首日、星期符号与月份名全部跟随系统语言环境（中文环境首日周日）。
- **点击**：打开日历.app。**长按**：弹出今日详情浮窗（公历短日期 + 星期 + 干支农历）。
- **跨天**：到零点自动切到新的一天；Mac 睡眠唤醒或抽屉重新展开时也会重新校准。
- **不做**：翻月、周视图、日程事件（不读系统日历数据，无权限需求）。想看别的月份或日程，点开日历.app 即可。
- **尺寸**：三档固定 150×150，可在网格里拖动，但不支持缩放（更窄会把日期数字压到不可读）。
