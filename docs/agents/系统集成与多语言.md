# 系统集成与多语言 — 领域约定

> [AGENTS.md](../../AGENTS.md) 的领域子文档：菜单/快捷键、休眠抑制、本地化等跨领域系统集成约定。

## 标准编辑快捷键依赖隐藏主菜单

accessory 应用没有可见菜单栏，程序化启动也没有带 Edit 菜单的默认主菜单，⌘C / ⌘V / ⌘X / ⌘A / ⌘Z 属于菜单键等价物——分发路径是 `keyWindow.performKeyEquivalent` → `NSApp.mainMenu` → nil-target 动作沿响应链落到 NSTextView。`EditMenuInstaller.install()` 在启动时安装这份不可见菜单（应用菜单保留 ⌘Q/⌘H），不要删除或改成给某个具体视图固定 target；否则笔记编辑器等文本输入的复制/粘贴快捷键整体失效（普通输入不受影响，回归见 `EditMenuInstallerTests`）。

## 保持唤醒需要管理员权限

`SystemSleepGuard` 通过 `osascript with administrator privileges` 调用 `pmset disablesleep`。**不要在单元测试里触发真实休眠抑制**；测试只验证命令字符串与 shell 语法（见 `SystemSleepGuardTests`）。

## 系统权限要诚实（日历 / 提醒 / 摄像头 / 屏幕录制 / 辅助功能）

权限清单、四态语义与跳转 URL 在 Kit 的 `SystemPermission`；宿主侧唯一门面是 `PermissionCenter`，「权限管理」弹窗是 `PermissionGuidePanel`。决策背景见 [`2026-09-11-permission-management-panel`](../agent-notes/implemented/2026-09-11-permission-management-panel.md)。四条红线：

- **缺权限只改变呈现，不改变可用性**：插件块在未授权时整块（或局部）切换为引导态，但**绝不抛错、绝不整页失败**，宿主其余功能不受影响。降级是每个需要权限的插件自己的义务。
- **系统授权窗的触发点只有一处**：插件不自行调 `requestAccess`，一律经 `HostController.presentPermissions(_:)` 弹权限管理窗，由用户在窗内显式点击发起请求——链路唯一、可审计，也避免插件在后台悄悄弹系统窗。
- **查询与请求必须分开**（`PermissionStatusProviding` / `PermissionRequesting`）：查询同步无副作用，请求会弹窗。单测只注入查询侧的假实现，**绝不触发真实授权窗**。
- **授权后需重启的要明说**：屏幕录制（`replayd` 缓存）与辅助功能（进程级 AX 缓存）在授权后**必须重启 App** 才生效（`SystemPermission.requiresRelaunch`）。UI 不写这句，用户就会以为"授权了但没用"。

权限清单与 `Resources/Info.plist` 的用途字符串键必须一一对应（`PermissionTests` 校验）；屏幕录制与辅助功能的 TCC **不读**用途字符串，故这两项 `usageDescriptionKey` 为 nil、只做跳转引导。

## 多语言（en / zh-Hans）

所有面向用户的字符串一律走本地化表，不许硬编码。机制是 Apple 原生 `.lproj` + `Localizable.strings`，每个模块自带翻译：

- 宿主用 `L()`/`LF()`（`Sources/NotchCenter/Localization.swift`，资源经 SPM 打进 `NotchCenter_NotchCenter.bundle`）；
- 插件用各自 Sources 里的 `L()`/`LF()`（基于 Kit 的 `L10n.string` + `Bundle(for:)`）；
- 插件的显示名/描述双语写在各 `Plugin.plist` 的 `DisplayNameLocales` / `DescriptionLocales` 字典（build.sh 生成 InfoPlist.strings）。

en 是基准键集，zh-Hans 必须保持键集合一致（`LocalizationTests` 强制校验）。语言跟随系统，设置面板可覆盖（写 AppleLanguages，重启生效）。品牌名（DSH、Calibre、OpenCode、Zen）不翻译。

注意 `L10n.string` 故意没有 CVarArg 变参重载：带参数的格式化必须在调用方自己模块内完成（`String(format:arguments:)`），变参跨动态库镜像转发会偶发段错误。
