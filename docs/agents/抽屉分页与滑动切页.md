# 抽屉分页与滑动切页 — 领域约定

> [AGENTS.md](../../AGENTS.md) 的领域子文档：多页面模型、分页胶囊、滑动切页的完整机制与真机教训。动到 `DrawerPageCapsule.swift` / `DrawerPageSwipe.swift` / `DrawerScrollProbe.swift` 或相关控制器代码前先通读本文。

## 抽屉多页面：显示序列可排序、索引恒为身份、算法页内隔离

页面持久化为 `LayoutModel.drawerPages`（**保序**去重、必含主页 0；数组顺序 = 顶栏胶囊从左到右的次序，空页面也必须持久化）。`normalizedPages` **绝不排序**——排一次序就把用户的拖动排序抹掉了。

**索引是身份不是位置**：拖动排序只改数组顺序，块上的 `page`（旧 JSON 缺省视为 0）永不重编号；新页索引只在既有**权值**外侧生成（左 = `min−1`、右 = `max+1`），乱序下拿 `drawerPages.first/last` 当极值会撞出重复索引、把块挂到错的页上。

页面可以**删除**（`removeDrawerPage` 连页内块一起删并返回被删块，调用方逐个补 `placementWasRemoved`；主页恒在不可删）——块与页必须**同一次写盘**里消失，否则加载净化的"收编块引用散页"会把刚删的页复活；非空页删除前须二次确认（块里可能装着用户笔记）。

页面可以**改名**：`drawerPageTitles` 按索引的字符串形式为键（Int 键会被合成的 `encode(to:)` 写成数组、与自定义解码不对称），显示名唯一解析点是 `LayoutModel.pageDisplayName`（标题优先、否则序列 1-based 序号），胶囊 tooltip 与确认框共用它。

所有网格算法（重叠/推挤/压实/几何/净化/校验）只作用于**同一页内**的块——新增页内操作时必须按页过滤 others；压实按页分组执行且不得改变块在 `drawerBlocks` 数组中的相对顺序（ForEach 稳定性）。激活页是运行时状态（`uiState.drawerActivePage`，不落盘），`rebuildContent` 按它过滤块元素与几何，设置面板拖入 / 快捷添加落位也落在激活页。**滑动切页的相邻页按序列位置取**（`neighborPage` 用 `firstIndex(of:) ± 1`，不比索引大小）。

分页控件（`DrawerPageCapsule`）是**每页一颗定宽独立胶囊** + **胶囊行首尾两颗常驻加号**（在胶囊外，封顶 `LayoutModel.maxDrawerPageCount` 后隐形且不吞点击）；胶囊主体**不得是 `Button`**（按钮会在 AppKit 层接管按下，鼠标拖动的中间事件直到松手才回流给祖先手势，真机上表现为整行只在松开那一瞬才动），点击切页与拖动排序共用同一条 `DragGesture(minimumDistance: 0)`、按横向位移越阈分类（与 Kit `blockPopoverTrigger` 同一实测结论），非编辑模式只认点击。

落点数学见 `DrawerPagePillLayout`：

- **被拖胶囊的基座钉在原槽位**（跟手量才是纯 offset），其让位预览 `displayIndex` 必须与引擎 `moveDrawerPage`（remove + insert）逐位同解，且**先提交再清预览**（清预览那两行须显式 `withAnimation(DrawerAnimation.spring)`，与 `rebuildContent(animated:)` 的换序同曲线），否则松手一次回弹；
- **胶囊行自身（`DrawerPageCapsule.body`）不得挂任何 `.animation(value:)`**——`targetIndex` 每越过半格边界变一次，行级隐式动画就把同一帧里被拖胶囊的跟手位移一起 spring 化，真机上胶囊落后于光标（与滑动切页"跟手不加动画"同源），让位动画只挂在各胶囊自己的 `shift` 上；
- 编辑拖动排序期**高光层必须跟随激活页胶囊**（高光常驻后与胶囊让位同步的配套约定）：target 越界时借高光自身的 `.animation(DrawerAnimation.spring, value: 锚定槽位)` 与胶囊 `shift` 同帧同曲线（触发键是**离散槽位**且**滑动会话期恒为 -1 不触发**——跟手逐帧直渲、落位回弹由自驱弹簧逐帧直渲，不得动画化位置本身，会话期沿用"跟手不加动画"）；
- 被拖的就是激活页时，胶囊的跟手位移经 `onDragOffsetChanged` 逐帧上报到父级 `dragOffset` 镜像，高光叠加该位移（基座钉原槽、位移一致、松手提交随预览一起清空），否则"胶囊在滑、高光瞬跳/原地不动"；
- 胶囊的**位移层必须排在拾取弹簧子树（scale/shadow 的 `isDragging` 动画）之后**——`isDragging` 翻转那帧 `dragOffset` 首次出现的跳变若被拾取 spring 化，胶囊会滞后于光标而与高光错位（跟手位移必须直渲，只让 `shift` 变化走 spring）；
- 拖动排序提交后**胶囊内容换字（序号重排）走淡入淡出**：`.id(label)` + `.transition(.opacity)` + `value: label` 动画，不做随行平移（label 只在提交变，会话期不变，不波及滑动期内容亮度逐帧直渲）；
- 胶囊**命中框比胶囊高一档**（`rowHeight`），编辑模式的重命名/删除角标必须落在框内——探出框外时指针一移到角标上 `onHover` 就翻回 false，角标当场消失、永远点不到。

回归见 `DrawerPageTests`（含对着真引擎穷举的"预览 == 提交"）与 `DrawerPagePillLayoutTests`。

## 抽屉左右滑动切页：两条输入、一份判据、跟手滑入

判据全在 `DrawerPageSwipe`（方向门槛 / 横纵压比 / 跟手位移与橡皮筋 / 落位阈值与速度 / 连页衔接与越点 / 无边界设备冷却），触控板轻扫与背景拖拽共用——不要在视图里各写一份，手感会漂移且无法重放。**判定与会话住在控制器**（`handleDrawerScroll` + `beginDrawerSwipe`/`updateDrawerSwipe`/`endDrawerSwipe`），落位/回弹由自驱弹簧 `DrawerSwipeSpringDriver` 驱动（见下），`NotchPanel` 只经 `onScrollEvent` 转发滚轮事件（与既有 `onMouseEvent` 同族）——窗口不知道页宽、块矩形和切页守卫。

触控板通路三条铁律：

1. **必须过滤 `momentumPhase`**（一次猛扫的惯性尾巴足以再翻一页；写 `momentumPhase.isEmpty`，**不能写 `== .none`**——`NSEvent.MomentumPhase` 没有 `none` 成员，`.none` 会被解析成 `Optional.none` 并隐式提升比较，恒为 false，真机上表现为轻扫全部失效）；
2. **必须不消费事件**（块浮窗、笔记编辑器、文件架都靠派发下去）；
3. **光标落在块上的让路判据是子树探针**（格 → 屏幕走 `drawerElement(at:)` + `drawerScreenMapper`）：经 `DrawerScrollProbe` 核实"光标下确有横向溢出的滚动视图"才让路——静态卡片与纵向 ScrollView（无横向溢出，如亮度滑杆块）放行切页（"在不使用滑动的组件上滑动时触发页面滑动"），空/未满的横向 ScrollView 亦放行。块级 `scrollUsage` 声明体系已删除（2026-09-06，最低支持提至 macOS 15 后探针反向推断恒可信）；探针看不见的非 ScrollView 横向手势块会双响应，已知取舍。**让路只在会话建立前判定**：会话一经接管/建立（越过方向门槛）即锁定整段手势、不再重跑探针（触控板与拖拽两条通路同此）——会话中页带滑行与面板尺寸插值让探针的实时 NSView 几何漂移，重探针会把已开始的切页中途弹回（真机：轻扫途中暂存区滑到光标下打断切页，2026-09-06 修）；会话期穿越横向溢出 ScrollView 时块内跟随滚一点，同属已知双响应取舍。**例外：在飞会话（自驱弹簧运行中）的新手势接管前逐帧探针**——光标压横向溢出块则让路（驱动器继续落位、块消费滚动），接管成立（取消驱动器）后回到会话锁定。

**让路探针（`DrawerScrollProbe`）**：从抽屉窗口 `contentView` **向下 DFS 子树**收集 `NSScrollView`（及不在任何 `NSScrollView` 内、带 documentView 的 `NSClipView`），"光标落在其可见区内 ∧ documentView 横向溢出视口（ε=1pt）"才让路，空/未满的横向 ScrollView（如文件架）放行切页；探针按滚动事件现查（子树仅数百节点、仅光标落在块上才走，无缓存无失效 bug）。**探针的正确起点是窗口 contentView，命中链 walk 仍然禁**：SwiftUI 在 `NSHostingView` 层接管事件路由，`hitTest` 永远到不了内部滚动机构，旧的"沿 superview 找文档视图宽于视口的 `NSScrollView`"实测恒 false；而 SwiftUI ScrollView 内部是真实 NSView 链 `DocumentView > NSClipView > HostingScrollView`（私有 NSScrollView 子类，macOS 15 实测），子树枚举必然访问到。反向推断（没找到 → 放行）恒启用——最低支持已提至 macOS 15（2026-09-06），旧盲区回落分支随块级 `scrollUsage` 声明体系一并删除；诊断日志 `NOTCHCENTER_SCROLL_PROBE_LOG=1`（候选/溢出/判定，真机核实内部结构能否枚举到）。

滑动是**跟手**的：`pageSlide` 是**单一常驻页带**——一个 ForEach 同时承载稳态页与会话（元素源见 `bandItems`），会话期 = 原点页（随 `offset` 平移）+ 目标页**真实例**（`isPreview: false`，随 `offset + gap` 平移、整层禁命中）构成一条**刚性页带**，两层之间隔一条**页带留白** = 两倍内容边距（`DrawerPageSwipe.bandSpacing`）的背景带，看得出是两页；`gap` 在 `beginDrawerSwipe` 按两侧页宽 + 留白一次算出并冻结——**不得在视图里现算 `ui.drawerContentSize.width`**，落位动画途中当前页尺寸会换，现算就让两层错开一条缝。跟手期只改 `uiState.drawerSwipe.offset`，**面板尺寸随同一份进度插值**（`updateDrawerSwipe` 把 `drawerWindowSize`/`drawerContentSize` 在会话起止两端间线性插值：滑动推进 → 面板同步向目标页所需大小长/缩，往回滑 → 进度归零、尺寸恢复，进度 = `|offset| / |gap|`，见 `DrawerPageSwipe.progress`/`interpolatedSize`）。

插值的两端（`startWindowSize`/`startContentSize`/目标两尺寸）与位移上限（`limit`）**全在会话里冻结**（唯一例外：覆盖点前进帧整值换锚，见下）——`drawerContentSize` 在插值，位移换算/橡皮筋若现读它就逐帧漂移（`handleDrawerScroll`/`drawerSwipeDrag` 一律取 `session.limit`）；`pageSlide` 的条带宽（内层 frame）也必须冻结为 `startContentSize.width`——若 bounds 跟着插值收窄/变宽，拖拽面/落点占位随之伸缩，两层之间的留白条就会偏离冻结值（层间距必须恒等于留白）。

**胶囊高光层**：同一份 `progress` 也是胶囊高光层的进度源——`DrawerPageCapsule` 在激活/目标两颗胶囊间线性插值**悬浮高光组件**（独立 `PagePillHighlight`，`DrawerPagePillLayout.highlightX` 定左缘），高光层**常驻**（永不消失/变淡：静止钉在激活页胶囊上、会话期在激活/目标间平移、落位/回弹全程满不透明度）——胶囊壳已**取消选中态**，只有「本身 × 悬停」两档（0.055/0.10、描边 0.06，`DrawerPagePillAppearance`），选中区分完全由高光承担；内容（图标/文本）亮度保留变化（`contentActivation`）作"内的呼应"；旧"会话期 `isActive` 让位"与 `suppressesCapsule` 方案均已删除——高光必须是**悬浮组件**观感：填充/描边 0.24（显著实于 0.055 底衬，盖住底下底衬、吞掉胶囊/间隙交界处的明暗变化）+ 投影阴影（`highlightShadow*` 常量，把高光从底衬平面抬起；不做这两点就是"同平面第二颗胶囊"，叠加/断裂的衔接问题复现）——胶囊内**内容亮度**（图标/文本）同一来源同步插值：`contentActivation` = 激活槽 (1 − p) 渐暗、目标页 p 渐亮、其余 0（`activationWeight`，与高光互补呼应）。高光必须用 `.offset` 定位、**不能用 `.position`**（`.position` 布局尺寸恒等于父容器提案，会把胶囊行 ZStack 撑满整行、行对齐把胶囊钉到容器左边，真机报告过）；落位 spring 期间高光随 offset 同曲线收敛，`rebuildContent` 清会话后静态激活样式恰好落在新激活胶囊上、无跳变。

**落位判据与提交**：落位门槛取 `min(页宽 × 0.28, 90pt)` + **速度判据**（`shouldCommit` 的 `velocity:`/`predictedOffset:` 两条通路：触控板经 `DrawerPageScrollTracker` 的样本窗口（0.12s）估即时速度、拖拽经 `DragGesture.predictedEndTranslation` 折成预测位移——≥ `commitVelocity`(800pt/s) 且与位移同向即落位，慢推/往回甩不触发），越界按 0.35 阻尼橡皮筋，提交只在松手/抬指（`onEnded` / `.ended` → `finish`）。**有手势边界的通路不设提交冷却**——惯性尾巴由 `momentumPhase` 过滤挡掉、`.began` 重置防串手势，压冷却纯属输入锁定期；无边界设备（`phase` 恒空）等不到 `.ended`，就地提交后的 `DrawerPageSwipe.cooldown` 是它们唯一的防连翻手段，不可删。**覆盖点前进（连页）后 tracker 重锚**：位移、反手换向与提交判据都只看锚后增量（`reanchor()` 钉下并丢弃速度样本窗口——跨带差商无意义，锚前残速会把锚后轻推判成第二次提交），一次手势可连续吃多页；无更远邻居硬停在覆盖点（与首/末页"不得滑过起点"同一语义）。

**落位/回弹由自驱弹簧驱动（`DrawerSwipeSpringDriver`），绝不回到 `withAnimation(completion:)`**：触控板通路经 `NSPanel.sendEvent`（AppKit 上下文）进来时 completion 实测不保证触发——被推迟到之后某次 SwiftUI 更新才冲刷，期间无人再动这些状态就永不触发，会话以 `isLanding` 卡死、两条输入全灭（兜底时钟曾是它的补丁，2026-09-06 随重构删除）。驱动器用解析解阻尼弹簧（`ω_n = 2π/response`、`ζ = dampingFraction`，与 `DrawerAnimation.spring` 同参映射；衰减因子只乘一次进整体——初版把它重复乘进速度首项，流性质破坏、接管种子漂移）逐帧把**表现值**写进 `swipe.offset` 并按同一进度插值面板尺寸——**状态值 ≡ 屏幕表现值**是本机制的根约定。收敛（|x−to| < 0.5pt 且 |v| < 8pt/s，另有 1.2s 安全上限）由驱动器自己的数学触发收敛拍：精确贴到目标后落位转正（`.land`）或散场（`.dissolve`），`DrawerSwipe.id` 守卫保证过期身份空跑。**tick Timer 必须挂主 RunLoop `.common` 模式**——触控板手势期间主线程在 event tracking mode，默认模式不点火；解析解逐帧求值无积分漂移，Timer 抖动不影响表现值正确性。

**动画全程可接管（grab），无输入锁定期**：驱动器在飞时任意新输入帧（触控板任意相；无边界输入须等冷却外）即接管候选——取消驱动器，以当前表现值为**种子**（`gestureSeed`）、当前输入位为**锚**（拖拽 `gestureAnchor` / tracker `reanchor()`）续接跟手，接管帧增量为零、带不瞬移；后续跟手位移 = 种子 + 锚后增量 × 屏幕换算比（`|gap|/|limit|`）。接管前光标压横向溢出块则让路（见铁律 3 例外）。

**前进/落位转正同一事务语义**：目标页真实例就地转正（`drawerElements := session.elements`，**绝不走 `buildDrawerElements` 重建**——同一 ForEach 身份、零重挂载）+ 激活页/左列同帧切换，位移经 `advanceCarry`（= 旧位移 + 旧 gap）**像素连续衔接**——此刻基座网格与页带目标层像素完全重合、旧原点页整层在视口外、新目标页整层在视口外，交接不可见。**原点锚（起点两尺寸）在前进帧重冻结是唯一合法例外**：此刻 p=1、起点与插值终点重合，整值换锚自洽；反手换绑仍绝不得重冻结——中途值当起点会让回弹终点变中间值、尺寸卡死（旧实现的次生缺陷）。落位转正后同事务散场（清会话 + `rebuildContentAfterPageChange` 按缓存键复用同一批视图值），无输入锁定期。绝不允许在松手那一帧停贡献 + `selectDrawerPage`：那会把停贡献、位移归零与换页挤进同一条 spring，真机表现为目标页原地淡出、新页内容再从反方向滑一遍。

**会话贡献在转正帧就地停掉**（`pageSlide` 的 `bandItems` 按 `targetPage != activePage` 门控把 `swipe.elements` 叠进页带）——前进/落位把目标页元素转正为 `drawerElements` 且激活页同帧切换，停贡献是防同一 placement 以重复 id 出现在 ForEach 里，不是"撤层换层"；也不能拖到 animated 清理才停（目标页更宽时会探回已变宽的裁剪框，旧两层结构真机报告过右侧重影）。

配套两条禁令：`pageSlide` 页带上跟随条带身份/位置的两条 `.animation(value:)` **在会话挂载期必须为 nil**（转正帧旧原点页成批卸载，否则重影淡出）；`beginDrawerSwipe` 只在无会话时建房、其早退**不得**走"清掉会话层"那条分支（会把滑到一半的层凭空抹掉）。页带几何的成立条件：条带宽冻结在会话起点值 + 容器宽度随插值——两层间距全程恒等于页带留白（留白条显示的是抽屉背景，是有意的页间分隔，不是裸露边缘；旧版"末帧露当前页边缘、靠落位后尺寸 spring 收场"的代价已随插值消失）。

拖拽层仍只挂在 `pageSlide` 页带的 `.background` **兄弟层**（`highPriorityGesture` 只为压过外层 ScrollView 对鼠标拖动的接管，与 `SettingsPages` 同一结论）：**不得改挂到 `content` 或任何祖先上**（块靠 `DrawerBlockContainer` 无条件的 `contentShape(Rectangle())` 认领自己的矩形，背景层因此只收得到真空隙上的按下）。

滑动**不自动建页**、越界无动作（`LayoutModel.neighborPage`，按显示序列取相邻）；编辑模式与默认状态一致可滑动——空隙上的背景拖拽与触控板轻扫均跟手切页，仅在块拖拽/缩放或胶囊拖动排序的预览进行中暂停切页（`PanelUIState.isDrawerInteractionActive` 由 `DrawerPanelView` 的 `DrawerInteractionState` + 胶囊拖动聚合写入），松手后恢复，避免把按激活页计算的推挤预览提交到错的页上；在飞会话不暂停新滑动（随时接管，见上）。可切性守卫集中在 `NotchPanelContent.canSwitchDrawerPage`/`canSwipeDrawerPage`，胶囊与两条滑动通路共用。

组件页拖拽跨页走**驻留切页**（第三条切页通路，`CapsuleDwellTimer` 一枚计时器两条路径共用）：拖拽中指针压在分页胶囊上驻留 0.5s 即切该页（iOS 桌面拖图标到屏幕边缘翻页的同款交互；快扫而过不切，停下即切）。**为什么必须 Task 计时**：驻留 = 指针静止压在胶囊上，此时没有任何鼠标事件流入，逐事件判 deadline 永远到不了点。到点前须用最近指针复核仍在同一颗胶囊上。

两条路径的落位动作不同：**设置目录拖拽**（`BlockDragCoordinator`）到点只切页（`switchDrawerPageForDrag`），松手落位按切换后的激活页算；**抽屉内重排**（`DrawerInteractionState`，`onDragChanged` 末尾喂 `NSEvent.mouseLocation`——手势 translation 只对块局部有意义）到点走 `moveDraggedBlockCrossPage`：清落点占位 → 引擎 `moveDrawerBlockCrossPage`（**保留 placementID**——插件实例状态键；原页摘除压实、目标页 `nearestFreeOrigin` 最近可用落位）→ 切页。被拖块的 `ForEach` 身份随 placementID 保留、拖拽手势跨页续走，松手在目标页内精确落位；框架重建身份时退化为"块已落目标页、拖拽静默结束"，两种结局都不丢块不错页。

它是 `canSwitchDrawerPage`"拖拽进行中"禁令的**唯一例外**，成立前提是调用时序——指针压在胶囊行上时目录路径 `dropZone` 判顶栏、`dropPreview` 已同帧清空；抽屉路径由 `crossPageMove` **先清落点占位再切页**，落位预览不存在错页写入。命中数学（行宽 / 行心编辑偏移 / 就近取槽）集中在 `DrawerPagePillLayout`，回归见 `DrawerPagePillLayoutTests`（命中数学）、`LayoutEngineTests`（跨页搬移）与 `DrawerInteractionStateTests`（驻留时序）；决策记录 `docs/agent-notes/proposed/2026-09-05-drag-dwell-page-switch.md`。

编辑期内块手势与滑动互斥：`DrawerBlockContainer` 在 `ui.drawerSwipe != nil` 时禁用拖拽/缩放手势，`DrawerPagePill` 在滑动会话期禁用胶囊拖动排序；反向则由 `isDrawerInteractionActive` 守卫让滑动让路——两者通过 `PanelUIState` 互知，避免同一指针的两份水平位移抢同一份 `offset`。

回归见 `DrawerPageSwipeTests`（含速度判定、进度/尺寸插值与预测终点落位、覆盖点衔接与越点判据、重锚判据切分）、`DrawerSwipeSpringDriverTests`（解析解性质 / 收敛拍 / 身份守卫）与 `DrawerPagePillLayoutTests`（高亮层平移）。

## isPreview 契约与真实例页带（2026-09-06 起）

**滑动切页已改用真实例页带**：`beginDrawerSwipe`/换绑以 `isPreview: false` 构建目标页并回写视图缓存，落位把会话 elements 直接转正为 `drawerElements`——滑动中显示的就是落位后的同一批视图，落位零重挂载。旧"预览副本整层换真实例"的结构位切换是落位闪烁根因：暂存区缩略图 `@State` 归零回退文件图标、监控重挂探针。副作用随真实例挂载即发生（监控开采样、缩略图加载、DDC 枚举、Notes 绑定编辑器/恢复选区），滑动开始即预热；会话目标页整层禁命中，回弹则随卸载走正常 onDisappear 清理。

**`isPreview` 契约暂留但滑页不再产生预览副本**：`buildDrawerElements(page:isPreview:true)` 参数与各插件短路分支（NotesPlugin 的 `EditorFocusBinder.bind`、选区恢复/聚焦、`unregisterPlacement`，剪贴板/监控的生命周期登记，媒体命令与 DDC 写入守卫）保留为护栏，清理另行 PR。若未来任何路径重建预览副本，插件侧义务不变：共享交互状态绑定与生命周期副作用必须为它短路——`bind` 是 `makeNSView`/`updateNSView` 无条件触发的，而 `textView`/`containerView` 是 weak，副本整层消失会把在屏实例的引用顶成悬空（与"多屏同实例"同一族事故，参见 [`面板与抽屉.md`](面板与抽屉.md) 的隐藏窗口复活一节）。

**编辑态视觉一致性**：页带块统一走 `DrawerBlockContainer` 单一渲染路径（`bandBlockContainer` 按元素来源注入渲染几何与条带位移，`isInteractive` 禁命中），编辑压暗层/描边同值同圆角——旧 `previewGrid`/`previewBlock` 双路径与"预览素面 → 落位后突然压暗"的闪烁一并删除；编辑角标随悬停逻辑自然隐藏，不在滑入页常驻。
