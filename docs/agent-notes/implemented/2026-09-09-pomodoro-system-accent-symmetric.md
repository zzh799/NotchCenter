# Agent Note: 番茄钟跟随系统强调色与对称居中

status: implemented
date: 2026-09-09
deciders: 用户

## Context(背景与约束)

前一版重做（`2026-09-09-pomodoro-ui-redesign`）给专注/休息/微休息各配了自有阶段色（红/绿/黄），运行头部的左右分栏（状态左、倒计时右）与控制行左贴边。本轮用户拍板两点：强调色一律跟随系统强调色、不再维护番茄色板；UI 摆放左右对称。out of scope：引擎/统计/摘要/音效/块像素三档与探针机制不动（探针数值随新版式更新）。

## Decision(决策)

- 删 `PomodoroTheme` 三阶段 RGB 常量，`accent(for:)` 改为活动阶段统一返回 `Color.accentColor`（idle 仍白）：状态区分由符号（timer/leaf/eye）与文案承担，不再用色相区分阶段。`scan-ui-tokens` 基线中 `PomodoroTheme` 的 3 项豁免清零（`--update-baseline` 重写快照，只降不升）。
- 运行中改垂直居中对称栈：状态单行（圆点 + 阶段名 + · + 今日完成，整体居中）→ 倒计时居中（28 等宽保留，计时是主角）→ 全宽进度条 → 控制钮居中行；去掉 `Spacer` 贴边。
- 空闲态改垂直居中栈：徽章 → 开始按钮 → 时长副文案，整体居中（原横向徽章+文案改为纵向，保证镜面对称）。
- 高度约束（2×1 最小高 120）倒逼两处收紧：控制钮直径 28→24（仍大于触击下限），纵向内边距 10→8（横向保持 10，对标 `DisplaySlidersBlockView` 紧凑 insets `8/10/8/10`）；行距仍 8、倒计时仍 28。核算：运行 8+18+8+34+8+4+8+24+8=120 恰顶满最小高（校验器含 0.5 容差取等通过，字体漂移由 CI 探针门禁捕获），空闲 40+8+30+8+13+16=115 ≤ 120；探针同步为四区带（状态 18 / 倒计时 34 / 进度 4 / 控制 24，含倒计时行——此前三区带漏了最高行）。

## Alternatives considered(备选方案)

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 保留三阶段色，只把专注红换系统色 | 阶段一眼可辨 | 休息绿/微休息黄仍是自有色板，违反"不使用番茄色" | 否，全跟系统色 |
| 暂停态用灰、运行态用系统色 | 多一维状态表达 | 暂停已有"已暂停"文案 + 播放图标，颜色再编码冗余 | 否，暂停/运行同色 |
| 保持左右分栏、只居中控制行 | 改动最小 | 头部仍是左重右轻的非对称 | 否，全栈居中 |
| 倒计时与按钮同行以省高度 | 纵向更宽松 | 28pt 数字与圆形钮同行基线难对齐，计时主角被挤 | 否，保持四行栈 |

## Consequences(影响)

- `PomodoroTheme.swift` 不再含任何 `Color(red:)`，token 扫描基线更新；`accent(for:)` 签名不变，调用点零改。
- 高块（max 240）下内容整体居中，对称保持；`verify-sizes` 按新探针重验。
