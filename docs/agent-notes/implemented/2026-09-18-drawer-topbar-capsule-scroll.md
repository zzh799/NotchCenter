# Agent Note: 抽屉顶栏侧按钮钉死 + 胶囊行溢出可滚

status: implemented
date: 2026-09-18
deciders: 用户（四项分支选择：加号随行滚动 / 会话期随进度跟随 / 一并做边缘自动滚 / 自由滚动）

## Context（背景与约束）

- 现状：顶栏是 `HStack{[齿轮][编辑时一键重排] Spacer [胶囊行] Spacer [钉住]}`（`DrawerPanelView.topBar`），胶囊行刚性定宽（`DrawerPagePillLayout.rowWidth` = 52 + 56×页数，含两端加号）。宽度不足时刚性内容整体溢出、被窗口裁掉——**齿轮与钉住被挤出可视区**（用户报告）。
- 量化溢出是常态而非边缘：`cellWidth` 75 + 3 列（两者都是允许下界）时顶栏可用宽 ≈ 217pt，两颗侧按钮 + HStack 间距已占 ≈ 80pt；默认档（150pt 格宽 / 3 列）下也只容得下 6 页，而页数上限是 9（`LayoutModel.maxDrawerPageCount`）。
- 约束：胶囊行的选中高光、拖动排序落点、以及"拖块到胶囊上驻留 0.5s 切页"的命中数学，全部建立在**行宽与行左缘是确定值**这一前提上（`DrawerPagePillLayout` 单测锁死）。滚动这件事必须让三处共用同一份偏移输入，不能各自为政。
- out of scope：胶囊改可变宽/缩窄/换行（定宽等距是上述全部数学的地基）；紧凑区；面板宽度下限；加号改角标；偏移量落盘。

## Decision（决策）

1. **顶栏改三段**：左按钮组（齿轮 + 编辑时一键重排）/ 滚动区 / 右按钮组（钉住）。两侧按钮组恒定占据自身宽度、不参与压缩，胶囊行只在中间区域内裁切——侧按钮不可能再被挤走。
2. **偏移是运行时状态**：`uiState.drawerCapsuleScrollOffset`，域是**对称**的 `[-余量, +余量]`（余量 `DrawerPagePillLayout.scrollExtent` = (行宽 − 区宽)/2）。区域宽由视图经 `onGeometryChange` 发布到 `uiState.drawerCapsuleRegionWidth`（先例：`GlobalFrameReader` 的锚定矩形捕获），作为几何唯一真源——控制器不重新推导顶栏内边距与按钮组宽度。
3. **锚在滚动区中心**：`rowLeft = 区左缘 + (区宽 − 行宽)/2 − 偏移`，`offset == 0` 恒等于"行心对齐区心"，放得下与放不下同一套语义（放得下时余量 0、偏移恒 0 → 与既有布局与全部命中数学**逐字不变**）。**这是"面板宽度变化时胶囊不平移"的根据**：区左缘随面板宽度移动 Δ/2，而偏移不随宽度变，行心因此恒钉在面板中线上（旧"溢出即左对齐"把行左缘绑在移动的区左缘上，切页/改格宽会带整排胶囊平移 Δ/2，且"放得下 ↔ 放不下"跨档时从居中瞬跳到左对齐）。渲染前在视图内再夹一次（区域宽与页数都会变，不指望每个写入口都夹准）。
4. **输入让路**：横向滚动增量落在滚动区内**且行确实溢出**时，驱动行偏移并吞掉这次切页（否则双响应：行滚一次、页翻一页）；未溢出、或指针不在滚动区内时，顶栏横扫仍走切页（现行为不变，不留死区）。该分支排在切页通路的 `momentumPhase` 过滤**之前**——行滚动是真正的滚动，惯性尾巴照常喂它（切页那条"惯性尾巴足以再翻一页"的禁令不同源）。
5. **跟随（夹紧）**：切页（点击 / 滑动落位 / 连页前进）、增删页、拖动排序提交、展开时，把偏移夹紧到"激活胶囊完整可见"的最小调整量；滑动会话期用同一份 `progress` 在"露出激活"与"露出目标"两个夹紧值间插值，直渲不挂 animation（与"跟手不加动画"同规）。自由滚动：允许把激活胶囊滚出视野，夹紧只在上述时机发生。**滚动区宽度变化只夹紧、不强制回中**——自由滚过去的行不该因为用户去调了格宽就被拽回激活胶囊。
6. **拖动期边缘自动滚**：指针进入滚动区两侧 24pt 边带时按速率滚行（压入越深越快、迟到 tick 不跳步、顶到端点停表；主 RunLoop `.common` 模式计时，与 `DrawerSwipeSpringDriver` 同一教训）。**被拖胶囊的跟手位移必须同帧补偿滚动增量**：`effectiveDragOffset` = 指针位移 + 拾取后的滚动增量，且写进**布局表达式**（不做 onChange 回写——回写晚一帧就是可见的脱手滞后）；拖动排序落点改判行内位移（`targetIndex` 纯函数不动，只换入参），自动滚期间槽位映射因此自洽。三条拖块通路（胶囊排序 / 设置面板拖入 / 抽屉内重排）共用同一份**屏幕**指针上报。
7. **命中裁剪是硬要求**：`clipped()` 不裁命中，溢出到区域外的胶囊会抢走齿轮/钉住的点击与悬停。逐胶囊与加号按 `DrawerCapsuleVisibility` 判定：完全在视野外 `allowsHitTesting(false)`；只露一段时命中面裁到那一段（`PillHitSpan`——`contentShape` 只能管自绘视图，胶囊按压面正是不用 `Button` 的自绘层）；编辑角标只在**完整露出**时出现、加号（`IconCircleButton` 是 `Button`，命中形状在内部定死）只在**完整露出**时可点。
8. **纯几何落点**：`DrawerPagePillLayout` 新增区域宽/偏移/夹紧/可见性/露出指定槽位所需偏移/边带速率等纯函数，单测覆盖；`drawerPageCapsuleHitTest`（驻留切页）补偏移项与"滚动区外不命中"——行溢出时行坐标会盖到两侧按钮组上，这是既有命中数学**唯一**要改的一处。
9. **溢出侧渐隐**：有隐藏内容的一侧加 8pt 渐隐遮罩，滚到端点即消失；仅视觉，不参与命中。

## Alternatives considered（备选方案）

| 方案 | 优点 | 缺点 | 结论 |
|------|------|------|------|
| 真 `ScrollView(.horizontal)` 包住胶囊行 | 白拿滚轮/触控板/惯性 | 与既有铁律冲突：外层 ScrollView 会接管鼠标拖动（`pageSlide` 背景层加 `highPriorityGesture` 的注释记着这条），胶囊点击与编辑拖动排序会残；行还会进 `DrawerScrollProbe` 候选表（虽有 `drawerElement` 门控，仍多一处耦合） | 否决 |
| 加号钉在行两端不滚 | "加页"永远可达 | `rowWidth` 定义拆两段，行心偏移 / `hoveredSlot` / 驻留命中 / 拖动落点参照原点全部重算，单测大改 | 否决（用户选随行滚动） |
| 加号随行滚动 | 不溢出时数学一字不改，行宽仍是唯一真源 | 居中锚下偏移 0 时两端同时被裁，"行首加号常驻可见"没了——加页要先把行滚到某一端 | 采纳（用户确认） |
| 只在提交后夹紧跟随 | 实现最省 | 会话期目标胶囊可能已在视野外、高光被裁一段，落位后行才跟上，两个动作不同步 | 否决（用户选会话期跟随） |
| 不做边缘自动滚 | 改动面小 | 窄抽屉无法把胶囊/块拖到视野外的槽位，拖拽通路出现够不着的目标 | 否决（用户要求一并做） |
| 钳制保证激活胶囊始终可见 | 永远知道当前在哪一页 | 激活在首/末页时够不到行首/行尾，远页与加号不可达 | 否决（用户选自由滚动） |
| 顶栏横扫永远切页，行只自动跟随 | 零语义变更 | 9 页窄抽屉要点 8 次才到末页，手动滚不可得 | 否决 |
| 溢出时左对齐（偏移 0 = 行首） | 偏移 0 时行首与行首加号常驻可见 | 行左缘绑在随面板宽度移动的区左缘上 → 切页/改格宽时整排胶囊平移 Δ/2；"放得下 ↔ 放不下"跨档时从居中瞬跳到左对齐 | 否决（v3：与"胶囊留在原位"的需求冲突） |

## Consequences（影响）

- 代码：`DrawerPageCapsule.swift`（几何 + 偏移入参与渲染/命中门控 + 跟手补偿）/ `DrawerPanelView.swift`（三段顶栏 + 区域宽发布 + 拖动指针上报）/ `PanelUIState.swift`（偏移、区域宽与会话基座 `capsuleScrollBase`）/ `NotchPanelContent.swift`（让路、夹紧、会话跟随、自动滚接线）/ 新增 `DrawerCapsuleScrollDriver.swift` / `BlockDropTargeting.swift`（驻留命中补偏移与区外守卫）/ `BlockDragCoordinator.swift`（指针上报与收尾停表）/ `NotchPanelController.swift`（驱动器属性）。
- 测试：`DrawerPagePillLayoutTests` 补偏移/可见性/露出/速率 11 例，新增 `DrawerCapsuleScrollDriverTests` 8 例；全量 `./scripts/build.sh test` 703 例 0 失败，九道文档门禁全绿。
- 文档：`docs/agents/抽屉分页与滑动切页.md` 补"顶栏三段与胶囊行溢出滚动"一节（偏移真源/让路判据/跟随时机/自动滚/命中门控/驻留命中）；`DESIGN.md` 不描述顶栏结构，无需改。
- 真机验收清单（窄抽屉 = 75pt 格宽 + 3 列 + 9 页）：侧按钮常驻可点；行可滚且两端渐隐到位；**切页与改格宽时整排胶囊不平移**（只有激活胶囊将被裁时才最小位移）；行溢出时横扫滚行、未溢出时横扫切页；滑动会话高光与行同帧；拖动排序跨视野且胶囊不脱手；驻留切页命中正确；展开收起后偏移无残留。**本清单需真机走查**（编译期与单测覆盖不到 SwiftUI 命中裁剪的实际生效范围）。
- 已知取舍：自动滚只覆盖行端点带、无惯性；行偏移不落盘（每次展开按激活胶囊夹紧）；溢出侧渐隐不提示"还有几页"；半截露出的胶囊不出现编辑角标（要编辑先把行滚到位）；**居中锚下偏移 0 时两端同时被裁，两颗加号都在视野外**——加页要先滚到行的一端（"加号随行滚动"的既定代价）。
