# Agent Note: 服务卡窄块降级为「图标 + 名称」

status: proposed  
date: 2026-09-08  
deciders: 用户

## Context(背景与约束)

Calibre 与 DSH Web 两张服务控制卡在 1×1 窄跨度（Calibre minSize 75×60）下横向余量不足：指示灯（7pt 圆点）+ 名称 + 状态行 + 端口行 + 迷你开关挤在一行，名称与状态只能靠 `minimumScaleFactor(0.7)` 缩字硬塞，端口行还会随状态增减导致行高跳动。目标：窄块不再堆控件，只保留「图标 + 名称」，用底色 + 图标明度表达开关；紧凑态没有开关控件后，启停必须有一条不依赖子控件的入口。out of scope：最小尺寸与跨度配置、浮窗内的信息行（PID / 端口 / 自启）取舍。

## Decision(决策)

块宽度 < 110pt 时隐藏指示灯 / 状态 / 端口 / 开关，渲染居中「图标 + 名称」（SF Symbol 15pt + 10pt 名称）：开启态整块染系统强调色（`Color.accentColor`，半透明 0.55，圆角 10 对齐卡片壳）+ 纯白图标，关闭态不画背景（沿用 `BlockCard` 默认底）+ 淡白亮灰图标（`white.opacity(0.6)`），名称随开 / 关在 `0.92 / 0.58` 之间切换；不做外发光高光——状态由整块底色承担，图标只负责识别；≥ 110pt 保持原完整排布。配套交互改动：块点击从「打开网页」改为「启停服务」（`monitor.toggleRunning()`，busy 期间自行忽略），打开网页入口移入长按浮窗底部动作行，与「重启」并排等宽（浮窗高度不变），并给块加 `.help()` 纠正旧的「点一下跳浏览器」肌肉记忆。阈值与外观常量落在各插件的 `ServiceBlockCompactMetrics`，`isCompact(width:)` 为可单测纯函数。实现落点：`Plugins/{Calibre,Dsh}Plugin/Sources/*ServiceBlockView.swift` 与 `*Popover.swift`，单测见两个插件测试的 `testCompactLayoutThreshold`。

## Alternatives considered(备选方案)

| 方案                    | 优点                         | 缺点                                    | 结论            |
| --------------------- | -------------------------- | ------------------------------------- | ------------- |
| `ViewThatFits` 自适应选排布 | 不用硬编码阈值                    | 拟合结果受子元素最小尺寸牵动，编辑 / 缩放期易抖动，且阈值不可单测    | 否             |
| 维持现状（缩字号 + 截断）        | 改动最小                       | 窄块仍塞开关与状态行，7pt 圆点难读，端口行增减导致行高跳动       | 否             |
| 阈值 + 紧凑排布（本决策）        | 阈值可单测、两种排布职责清晰                | 需人工定阈值，常量在两个插件各一份要同步                  | 是             |
| 开启态：图标上系统色 + 同色外发光   | 图标本身就是状态，不占背景                  | 窄块里 15pt 图标的色相辨识度不如整块底色                  | 否，改用强调色底 + 白图标  |
| 开启态：固定 systemBlue / systemGreen 底 | 颜色稳定可预期                     | 与用户在系统设置里选的强调色脱节                        | 否，用 `Color.accentColor` 跟随系统 |
| 把紧凑排布抽成 Kit 公共组件      | 消除两份重复                     | 仅两张服务卡复用，Kit 属公共 API 面，为一个阈值扩 API 不划算 | 暂否，第二个复用方出现再说 |

## Consequences(影响)

两个插件各持一份同名 `ServiceBlockCompactMetrics`（改一处须同步另一处，文件头已标注）；紧凑态下没有开关控件，启停靠点击整卡；打包期 `BlockProbe` 几何不变（两种排布都是居中单行带，仍落在 minSize 盒内）；开启态底色是半透明填充，卡片发丝描边与按压增亮仍然盖在上层可见，不引入渐变或重阴影；`Color.accentColor` 跟随用户在系统设置里选的强调色，不同机器观感不同（预期行为，非 bug）。
