# 开发者工作流与文档门禁

> [AGENTS.md](../AGENTS.md) 的配套速查:doc-driven-dev v3 治理下,日常开发的完整 SOP、领域速查与提交门禁。长文与示例一律放 `docs/`,本文件不承载实现细节,只承载"怎么按规范干活"。

## 一、心智模型:这套规范是什么

治理落地的完整背景见决策记录 [`2026-09-02-doc-driven-dev-governance`](agent-notes/implemented/2026-09-02-doc-driven-dev-governance.md),日常只需要记住五层:

| 层 | 载体 | 职责 |
|------|------|------|
| 入口 | [AGENTS.md](../AGENTS.md) | 常驻指令与索引,预算 ≤2400 字符,只放“读哪、跑什么”,不放细节 |
| 领域红线 | `docs/agents/` 八篇子文档 | 各领域机制、历史事故、回归测试;**改到某领域前先读对应子文档** |
| 决策记录 | `docs/agent-notes/{proposed,implemented,rejected,archive}/` | 非平凡架构/接口/行为变更的"为什么",落地后 git mv 至 implemented,过期归档不删除 |
| 事故复盘 | `docs/postmortem/` | 线上问题修复附复盘,防二次踩坑 |
| 预算与术语 | [`doc-budgets.manifest.json`](../doc-budgets.manifest.json) + [TERMINOLOGY.md](TERMINOLOGY.md) | 文档字数上限与禁用词纪律,超限/增删走 PR 人工复核 |

## 二、日常开发六步 SOP

1. **改前必读**:先读 [AGENTS.md](../AGENTS.md) 定位入口;按改动领域通读对应 [`docs/agents/`](agents/宿主开发约定.md) 子文档(机制 + 历史事故 + 回归测试);涉及全局设计再补 [`NotchCenter 架构设计文档`](NotchCenter 架构设计文档.md) 与 [`DESIGN.md`](DESIGN.md)。
2. **判断是否需要决策记录**:非平凡架构/接口/行为变更 → 先在 [`docs/agent-notes/proposed/`](agent-notes/proposed/) 按 [agent-note 模板](templates/agent-note.md) 写 `<yyyy-mm-dd>-<slug>.md`(frontmatter 含 status/date/deciders;**非归档必须含 `## Alternatives considered`**,机器强制);纯修 bug、改文案、内部小重构可跳过。
3. **按领域红线实现**:见下方速查表;公共编码纪律--Swift 6 严格并发、主线程隔离(@MainActor)、标识符/UI 用英文、注释可中文、**不引入新的 SPM 远程依赖**、UI 字符串一律本地化(en 基准、zh-Hans 键集一致)。
4. **测试**:SPM 风格测试 target(Tuist 清单内为 `*Tests` 单元测试 target),命名一律 `*Tests`;跑 `./scripts/build.sh test`(定向复验 `./scripts/build.sh test <套件/用例>`);遵守[测试指南](agents/测试指南.md)的隔离约束(单测不真实改系统睡眠/launchctl/网络)。
5. **文档门禁**:合并前跑 [`./scripts/run-doc-checks.sh`](../scripts/run-doc-checks.sh)(7 项,见下);pre-commit 钩子会自动执行,CI([`docs.yml`](../.github/workflows/docs.yml))在 PR 与 push main 复验。改动 md 后本地先跑,别等钩子挡。
6. **落地归档**:决策实现完成 `git mv` 至 `implemented/`;被取代/过期记录移入 `archive/`(不删除);事故修复附 postmortem;PR 描述关联对应 agent-note。

## 四、文档门禁明细(7 项)

`./scripts/run-doc-checks.sh` 依次执行,任一失败整体 exit 1;可选 `--include-archived` 纳入归档目录。默认排除 `docs/agent-notes/archive/`、`.doc-driven-dev/`、`Vendor/`、`.zcode/` 及模板目录。

| 脚本 | 校验什么 |
|------|------|
| verify-md-links.sh | 内部链接目标存在(忽略 http/mailto/纯锚点) |
| verify-md-wrap.sh | 段落不得软换行(同一段落内无空行换行即违规;列表/表格/引用/围栏除外) |
| verify-agent-note-format.sh | agent-note 路径正则 + 非归档必含 `## Alternatives considered` |
| doc-budget-check.sh | `wc -m` ≤ 预算 max(依赖 jq) |
| verify-code-blocks.sh | 围栏闭合且必须标注语言;语言在白名单 `swift/bash/text/xml/json` 内 |
| verify-terminology.sh | banned 词命中即报(当前术语表为空,增删走 PR) |
| verify-scaffold-manifest.sh | 治理落地记录声明过的 artifacts 完整 |

## 五、预算与术语治理

- 仅 [AGENTS.md](../AGENTS.md)(target 2200 / max 2400)与 [TERMINOLOGY.md](TERMINOLOGY.md)(target 900 / max 1600)受限;超 max 即门禁红,**冻结需 PR 说明并人工复核**。
- 超限拆解顺序:搬走非本层内容 → 压缩本层 → 提上限;docs/ 其他文件无预算,但同样要过其余 6 项门禁。
- 术语纪律:banned→preferred 写在 TERMINOLOGY.md frontmatter(`banned: "词"` 行格式勿改,脚本只解析此处);当前 terms 为空,增删前先团队讨论,勿套模板示例词,防误伤 SwiftUI `Shape` 等专有名词。

## 六、历史坑 FAQ(均来自各子文档事故,勿重犯)

- 触发器手势不要改回 `TapGesture` + simultaneous 长按--真机点击不回调(用 DragGesture 管线 + longPressFired 抑制),回归见 BlockCardTriggerTests。
- 枚举判空写 `== .none` 不生效的场合改用 `.isEmpty`;分页数据 `normalizedPages` 排序会毁掉"索引即身份"。
- 协议成员若只放 extension 默认实现,宿主经存在类型 `any` 分发时会被静态遮蔽永不执行--settingsView、menuItems、服务钩子、活动接口都必须是协议**要求**。
- 窗口 frame 不参与动画(裁剪 spring 变形是既有教训,活动岛窗口机制已随摘要通道移除):摘要芯片/抽屉的进出动画一律发生在窗口内容内。
- 单测不要真实触发 pmset / launchctl / 网络请求;加载真实插件的测试用纯 Info.plist fixture。
- 新增插件目录后 build.sh 会 touch Project.swift 触发 Tuist 重扫（手工跑 tuist 时需自行处理缓存）；插件列表任何脚本/清单都不得手工维护。
