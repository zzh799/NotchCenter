## 剪贴板插件交互改造 + 宿主确认浮窗化

### 目标(已拍板)
1. **点击即复制**:条目主体点击 = 写回剪贴板,移除复制按钮;单行截断显示。
2. **删除+置顶同行**:两颗按钮横排显示在条目行尾(置顶左、删除右)。
3. **移除时间戳**:行内不再显示时间戳,「显示时间戳」设置项、配置字段、`time.relative.*` 字符串一并移除。
4. **长按浮窗预览全文**:长按条目 0.2s 用 `BlockPopover` 弹全文预览(替代原「点击展开」)。
5. **清空确认浮窗化**:抽屉内清空 = 覆盖卡片的确认层(用户选定);快速区图标 = `BlockPopover(.below)` 贴图标下方弹确认浮窗;快捷按钮盒 = 覆盖盒卡片的确认层。全部弃用 `confirmationDialog`。

### 实现要点

**A. Kit 新增共享确认组件** `Sources/NotchCenterKit/InlineConfirmOverlay.swift`
- `InlineConfirmPanel`(标题/说明/取消+确认按钮,确认键红色系)+ `InlineConfirmOverlay`(半透明遮罩盖底 + 居中 Panel + 点遮罩取消),圆角 10、深色环境、DESIGN.md 的 alpha/动画常量。
- 两者都监听 `.notchCenterDrawerDidCollapse` 自动取消——解决「视图在抽屉收起后仍存活、确认态残留」问题,不需要给 Store 加可见性标志。
- 字符串由调用方本地化后传入,组件本身不带文案。

**B. `BlockCard.swift` 小改**:`blockPopoverTrigger` 增加 `cornerRadius` 参数(默认 10 不变,行为零变化);条目行以 7 传入,按压增亮与行背景圆角一致。

**C. 剪贴板条目行重构**(`ClipboardHistoryViews.swift`)
- 行交互改挂 `.blockPopoverTrigger(onTap:onLongPress:)`(单手势管线,规避插件开发约定里 TapGesture+长按真机失效红线):tap → `store.copyBack`,长按 → `BlockPopover.shared.present(anchoredTo: 行frame, .overlay)` 弹全文预览卡(固定宽 ~280、高 ~200,内嵌 ScrollView,长文可滚)。
- 行布局:`HStack[置顶pin(如有) + ✓(刚复制1.5s,绿色,沿用 justCopiedID 链路) | 单行文本 lineLimit(1) | 置顶按钮 + 删除按钮]`;删除 `expandedID`/`isExpanded`/`onToggleExpand`/时间戳全部旧路径;contextMenu(置顶/删除)保留。
- 文件头交互分区注释同步改写(显式记录推翻共识 Q8/Q9)。

**D. 清空确认**(`ClipboardHistoryViews.swift`):删 `.confirmationDialog`,`confirmingClear` 改为卡片级 `.overlay { InlineConfirmOverlay(...) }`,复用现有 `drawer.clear.*` 四条字符串。

**E. 快速区确认**(`CompactPanelView.swift` 的 `QuickActionStripCell`):删 confirmationDialog;点击重动作时用 `GlobalFrameReader`(同文件既有)取图标 frame,`BlockPopover.present(placement: .below)` 弹确认浮窗(动作名 + `quick.confirm.body` + 取消/执行,复用现有键)。这是紧凑区齿轮设置浮窗的同款管线,鼠标不离开条带、无焦点抢占。

**F. 快捷按钮盒确认**(`QuickButtonBoxViews.swift`):`BoxActionButtonCell` 的确认态上提到盒卡片视图(@State pendingConfirm),卡片 `.overlay { InlineConfirmOverlay }`,复用 `confirm.run/confirm.message/common.cancel` 键;确认后 `action.execute()` 语义不变。

**G. 时间戳移除**:`ClipboardInstanceConfig` 删 `showTimestamps` 字段(旧持久化 JSON 多余键会被 JSONDecoder 忽略,无需迁移);设置视图删 Toggle;`ClipboardInstanceModel.update` 同步删参数。

**H. 字符串**:en/zh-Hans 删 `drawer.button.copy`、`settings.showTimestamps`、`time.relative.*`(先 grep 确认无其他引用);`drawer.button.copied` 保留给 ✓ 反馈的无障碍标签。
