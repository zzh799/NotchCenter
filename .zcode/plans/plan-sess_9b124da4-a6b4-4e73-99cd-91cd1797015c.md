# 去掉"保持唤醒"快捷按钮的蓝色边框

## 根因
蓝框是 **macOS 系统焦点环**，不是项目自绘描边（容器悬停底衬、发丝描边全是白色系，Caffeinate 激活底衬是深绿色）。链路：

- `Plugins/CaffeinatePlugin/Sources/CaffeinatePlugin.swift:85-104`：紧凑图标是 SwiftUI `Button` + `.buttonStyle(.plain)`；
- 紧凑面板 `NotchPanel` 的 `canBecomeKey = true`（PanelWindows.swift:14），抽屉展开时 `makeKeyAndOrderFront`（NotchPanelController.swift:270）；
- 点击后按钮成为 first responder → 系统画默认蓝色焦点环，焦点不移走就一直显示。

## 修复方案（保持 Button，禁掉焦点环；最小 diff）

1. **CaffeinatePlugin.swift** `KeepAwakeCompactView`：在 `.buttonStyle(.plain)` 后追加
   ```swift
   .focusable(false)          // 不参与键盘焦点，点击后不抢 first responder
   .focusEffect(.disabled)    // macOS 14+：即使获得焦点也不画焦点环（双保险）
   ```
   加一行中文注释说明动机。项目部署目标恰为 macOS 14+，`focusEffect` 可用；若工具链编译不过则只保留 `.focusable(false)`。

2. **PomodoroPlugin.swift** `PomodoroCompactView`（PomodoroBlockViews.swift:37）：同款写法同病同修，追加相同两个修饰符。

不改面板的 `canBecomeKey`（抽屉里的笔记编辑器需要 key 窗口），不动其他抽屉内按钮（用户未报告；后续若番茄钟开始按钮等也出现蓝框，可复用同样两个修饰符）。

## 验证
- `swift build` + `swift test`（确认编译与既有测试不回归）；
- 杀掉旧实例后 `./Scripts/build.sh run` 真机确认：点击"保持唤醒"图标不再出现蓝框（注意旧坑：`swift run` 不会杀旧实例，验证前先 pkill NotchCenter）。

## 回退预案
若真机上蓝框仍出现（SwiftUI 版本差异），改为与 Notes/Scratchpad 紧凑图标一致的写法：`Image` + `.onTapGesture` 替换 `Button`，补 `.accessibilityAddTraits(.isButton)` 保住无障碍语义。
