## 目标

设置 → 布局页中，「最大列数」（Picker 2...8）与「最小列数」（Picker 3...8）两个下拉合并为**一根双游标滑条**：左游标 = 最小列数、右游标 = 最大列数，游标下方实时显示数值；拖动过程中每越过一个整数档位，抽屉布局立即重建响应（复用现有逐档提交链路，无需新通知机制）。最小行数保持 Picker 不动。

## 改动清单

### 1. `Sources/NotchCenter/SettingsPages.swift` — `LayoutSettingsPage`

- **`columnsSection`（"列数"区）**：Picker 行替换为新自绘组件 `ColumnRangeSlider`（行标签沿用 `settings.columns`"抽屉列数"）。保留"当前屏幕最多容纳 N 列"脚注；当 `userMaxColumns < 3` 时追加显示现有 `settings.layout.minColumnsUnavailable` 提示（键复用，从最小尺寸区移来）。
- **`minimumSection`（"最小尺寸"区）**：删除「最小列数」行及配套 `minColumnOptions` / `minColumnsBinding`，仅留「最小行数」Picker；`settings.layout.minHint` 文案改写（去掉"最小列数不会超过最大列数"子句，en/zh-Hans 同步）。

### 2. 新组件 `ColumnRangeSlider`（同文件 private struct）

- **视觉**（DESIGN.md 白色层级 + systemBlue 语义色）：底轨 `RoundedRectangle(height 4, cornerRadius 2.5, .continuous)` 填 `white.opacity(0.10)`；两游标之间选中段填 systemBlue；游标 = 16pt 白色圆 + 发丝描边 + 轻投影，拖动中 scale 1.08。
- **手势**：整条滑条单条 `DragGesture(minimumDistance: 0)`（遵守项目"胶囊行不用 Button"的实测结论）；按下时取最近游标（距离平手取 max 游标），拖动中锁定该游标到松手；位置逐帧量化为整数列，**量化值变化才提交**（避免每帧 rebuild）。
- **提交路径（立即生效）**：min 游标 → `layoutEngine.setUserMinColumns(v)` + `controller.refreshAfterLayoutChange()`；max 游标 → `setUserMaxColumns(v)` + refresh。与现 Picker 逐档提交完全同路。
- **边界契约（不构造空 ClosedRange 防 trap）**：
  - max 游标值域 `LayoutModel.maxColumnsRange`（2...8）。
  - min 游标值域 = `min(3, maxColumns)...maxColumns`；maxColumns < 3 时 min 游标钉在 max 位置、不响应拖动（与 `setUserMinColumns` "忽略写入"契约一致）。
  - 显示值 `minThumb = min(userMinColumns, userMaxColumns)`（保留现 get 夹取，兼容手改 JSON）、`maxThumb = userMaxColumns`。
  - "不回改存量值"契约天然保留：max 拖低于存储 min 时 min 显示跟随，max 拉回后原设置恢复（引擎侧已有，UI 不额外写）。
- **值标签**：轨道下方两枚小标签，锚定各自游标 x（夹在轨道范围内），显示"最小 N 列"/"最大 M 列"（新本地化键）；将重叠时对称推开。
- 附 `.help()` 与 `.accessibilityLabel`（含当前范围，DESIGN.md 可访问性要求）。

### 3. 纯函数辅助 + 测试（项目惯例）

新增小纯结构体 `ColumnRangeSliderMath`（value↔x 映射、量化、最近游标选择、标签防撞偏移），新建 `Tests/NotchCenterTests/ColumnRangeSliderTests`：量化半档取舍、平手取 max、max=2 时 min 钉住、显示夹取、映射单调且两端对齐。

### 4. 本地化（en + zh-Hans 键集一致，LocalizationTests 强制）

新增 `settings.layout.columnMin`/`settings.layout.columnMax`（"最小 %d 列"/"最大 %d 列"）；改写 `settings.layout.minHint`；`settings.layout.minColumnsUnavailable` 移至列数区脚注继续使用。

### 不改的部分

`LayoutEngine` setter 契约与既有测试（`LayoutEngineTests`、`MinimumGridSizePersistenceTests`）、引擎/面板任何链路、`refreshAfterLayoutChange` 路径。

## 验证

`swift build` → `swift test`（新测试 + 既有回归 + 本地化键集）→ `./Scripts/build.sh run` 真机目检：拖动两游标时抽屉面板与网格逐档即时变化；max 拖到 2 时 min 游标钉住并出现提示；max 拉回后原最小列设置恢复；重启后设置保留。
