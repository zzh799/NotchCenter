# 剪贴板抽屉：删「置顶：/最近：」文字标签，改纯 UI 提示

目标组件：`Plugins/ClipboardHistoryPlugin/Sources/ClipboardHistoryViews.swift`（探索确认全仓库唯一使用该分组标签的组件；用户所说"简版组件"即此抽屉块）。

## 改动内容（全部在上述单文件 + 无 strings 变更）

1. **分区模型去 title 化**（`ClipboardHistoryViews.swift:233-237, 109-124`）
   - `ClipboardSection` 的 `title: String` → `kind: ClipboardSectionKind`（新增 enum `pinned`/`recent`，Hashable），`id` 返回 kind。
   - `displayedSections` 改传 kind，删掉两处 `L("drawer.section.pinned"/"drawer.section.recent")` 标题注入；同步更新 101 行与文件头 7-10 行注释。

2. **删文字标签行**（`ClipboardSectionView.body`，247-251 行）
   - 移除 `Text(section.title)` 及其样式，节视图只剩行列表。

3. **组间细线**（`historyList` 214-229 行 + `ClipboardSectionView`）
   - 非首节顶部画细线：`Rectangle().fill(.white.opacity(0.045)).frame(height: 1).padding(.horizontal, 12)`（DESIGN.md §2.3 编辑器分隔线基准），标记 `.accessibilityHidden(true)`；仅当置顶与最近两节同现时出现（即 `index > 0`），上下留白按 LazyVStack 现有 spacing 实测微调。

4. **置顶按钮选中态**（`iconButton` 345-358 行，行内调用 296-300 行）
   - `iconButton` 增加 `isActive: Bool = false` 参数：已置顶 → `pin.fill` + 亮白 `0.92` + 22×20 圆角微底 `white.opacity(0.08)`；未置顶维持 `pin` 描边半透明现状。help/a11y label 已区分 pin/unpin，不动。

5. **删行首 pin.fill 小图标**（277-281 行）
   - 按钮选中态已表达置顶，行首图标冗余，删除；`justCopied` 对勾逻辑不动。

6. **可访问性兜底**（不删 strings key）
   - 分组语义改由 VoiceOver 承载：节容器加 `.accessibilityElement(children: .contain)` + `.accessibilityLabel(L("drawer.section.pinned"/"recent"))`。两个 key 继续被引用，zh-Hans/en 无需改动，LocalizationTests 不受影响。

- `./scripts/build.sh run` 真机确认（注意先杀旧实例再启动）；确认三点：无文字标签、置顶行按钮呈选中态、两节之间细线只在同时有置顶+最近时出现。
