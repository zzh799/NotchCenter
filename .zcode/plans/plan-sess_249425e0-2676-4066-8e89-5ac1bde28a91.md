# 滑动切页重构：自驱弹簧 + 覆盖点前进 + 全程可接管

## 目标

1. **零输入锁定期**：落位/回弹动画未完成即可开始下一次滑动（删除 `isLanding` 门控、0.75s 兜底时钟、completion 双触发）。
2. **支持连页**：一次手势推过页面覆盖点即换绑到下一页继续跟手；动画中再刷可连翻（iOS pager 手感）。
3. **时序权威收敛为一套**：收敛拍由自己的弹簧数学触发，彻底删除 `withAnimation(completion:)` 依赖。

## 设计

### 1. 新建 `DrawerSwipeSpringDriver`（Sources/NotchCenter/DrawerSwipeSpringDriver.swift）

- **解析解阻尼弹簧**：从 `DrawerAnimation.spring`（response 0.3 / dampingFraction 0.86）映射 ω_n = 2π/response、ζ = dampingFraction，闭式解直接给出 presented(t) 与 velocity(t)（无积分漂移）。
- **时钟可注入**（`now: () -> TimeInterval`），单测可手动步进逐帧重放（与 tracker 注入 `NSEvent.timestamp` 同一风格）。
- **Timer 1/120s 挂 RunLoop `.common`**——触控板手势期间主线程在 event tracking mode，默认模式 Timer 不点火（已知坑）。
- 每次 tick：写 `swipe.offset`，按同一 progress 写 `drawerWindowSize`/`drawerContentSize`（走与跟手帧相同的 `updateDrawerSwipe` 写入路径，该路径已真机验证）。
- **收敛判据**（|x−to|<ε 且 |v|<ε）：贴到目标 → 触发 onConverge（前进+散场 或 纯散场）→ 停表。
- **身份守卫**：持会话身份（`DrawerSwipe` 新增 `id: UUID`），会话被换绑/清场后 tick 空跑。
- **接管 = cancel**：状态停在最后写入值 = 屏幕表现值，新手势从该值续接，零瞬移。

### 2. 覆盖点前进（origin-advance）——落位拍的推广

跟手期推过 `|offset| = |gap|`（目标页覆盖点）且该侧有更远邻居时，**同一事务**内：
- `drawerElements := session.elements`（目标页真实例就地转正，ForEach 按 placementID 身份保持、零重挂载——与现落位拍同机制）；
- `drawerActivePage := targetPage`、`drawerGridLeftColumn := leftColumn`；
- 会话换绑为 [目标页 | 更远邻居]（`rebind` 重算 gap/limit/elements），起点尺寸重冻结在覆盖点值（p=1 处插值终点≡起点，自洽，无旧"尺寸卡死"风险）；
- 越界余量换算进新带坐标（新增纯函数 `DrawerPageSwipe.advanceCarry`，按 gap 比例缩放），tracker 累加量 rebase。

无更远邻居：硬停在覆盖点（同首/末页边界语义）。反手回原点的换绑机制（`reversedSide` + `rebind`）不动。

### 3. 会话生命周期重写（NotchPanelContent.swift）

- `endDrawerSwipe`：commit → `driver.run(to: arrivalOffset, converge: advance + dissolve)`；回弹 → `driver.run(to: 0, converge: dissolve)`。dissolve = 清会话 + `rebuildContentAfterPageChange`。
- **删除**：`scheduleDrawerSwipeSettle`、`drawerSwipeSettleGrace`、两个 completion 块、`landDrawerSwipe` 拆分为 `advanceOrigin` + `dissolveSession`。
- **接管入口**：`updateDrawerSwipe` / `drawerSwipeDrag` / `handleDrawerSwipe` 相关帧发现会话存在即先 cancel driver 再喂帧；跟手 offset = 接管种子 + 映射增量。
- `canSwipeDrawerPage` 删 `isLanding` 条款；删 `PanelUIState.DrawerSwipe` 的 `isLanding`/`isLanded` 字段。
- 胶囊点击会话期忽略的门（DrawerPageCapsule:487）保持不变——会话收敛快（~0.4s）且接管即清，锁窗自然大幅缩短。

### 4. 视图侧（DrawerPanelView.swift）

- `bandItems` 目标层渲染条件 `!swipe.isLanded` → `swipe.targetPage != ui.drawerActivePage`：前进后 activePage 同帧更新，旧目标层自然退出、新目标层进场，身份保持机制不变（前进瞬间两层各自在视口外/覆盖点，交接不可见——与现换绑同一条"像素重合"原理）。
- 会话期关闭 item-change spring、`isSwipeActive` 禁命中、几何冻结等其余机制全部不动。

### 5. tracker 冷却收窄（DrawerPageSwipe.swift）

- **有手势边界通路（触控板 phased）**：删除 0.35s 冷却——惯性尾巴已被 `momentumPhase` 过滤、`.began` 重置防串手势，冷却当前是纯延迟（用户抱怨的"无反应期"组成部分）。
- **无边界设备（phase.isEmpty 就地提交）**：保留冷却（唯一防连翻手段，注释已言明）。
- `testOneGestureCommitsAtMostOnePage` 保留成立（tracker 层一次手势一提交；连页发生在页带层）。

### 6. 测试

- **改**：`testCooldownBlocksTheNextGesture`（phased 冷却取消、phase-less 保留）、`testLandedPreviewPokesBackIntoClipOnlyWhenTargetIsWider`（改钉新门规则）。
- **增**：驱动器收敛时序（注入时钟逐帧步进）、`advanceCarry` 数学、**接管连续性**（commit → 驱动若干 tick → 接管帧 offset 与表现值连续无跳变）、回弹散场身份守卫、连页会话断言（模型层）。
- 判据纯函数（side/offset/shouldCommit/velocity/gap/arrival）全部不动，现有测试存活。

1. 一次手势可跨多页（推过覆盖点连页）；动画中再刷即接管连翻。

3. 落位/回弹动画由自驱解析弹簧呈现（参数对齐现 spring，真机 A/B 手感，必要时微调 ζ）。

## 风险与对策

- **弹簧手感漂移**：CASpring 映射是社区标准公式；真机 A/B，必要时调 ζ。
- **事件跟踪期 Timer 不点火**：RunLoop `.common` 挂载；测试注入时钟覆盖。
- **接管种子在 rubber-band 极限的语义**：以带原点为基准做增量映射，边界细节实现时以"无跳变"为准。
- **提交格式**：沿用仓库惯例 `feat:/fix: 中文描述`。
